# Calculatrice
Calculatrice transforme A.V.A.T.A.R en véritable assistant de calcul vocal.

- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

 ## 🎯 Usage
Commandes :
- calcule 2 x 2 + 5
- combiens font 3 x 7
- tu peux me dire combien font 50 divisé par 2 s'il te plait

## Multi-room

The Calculatrice plugin is fully multi-room.

## Multi-language

The Calculatrice plugin relies solely on the system's available languages.
